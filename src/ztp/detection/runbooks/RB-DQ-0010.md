# RB-DQ-0010 — Log kesintisi / ajan sessizliği

**Amaç:** Cihaz kullanımdayken uç nokta telemetrisi kesildi.

## İlk kontroller (analist)
- Ajan durumu: servis kapalı mı, sürüm güncellemesi mi
- Kesinti anında cihazda kim oturum açtı
- Diğer kaynaklarda aynı cihaz görünüyor mu

## Yükseltme kriteri
Ajan kasıtlı durdurulduysa (süreç kaydı) Defense Evasion olarak yükselt.

## Bilinen yanlış pozitif kalıpları
- Ajan güncellemesi / yeniden başlatma
- Uyku modu (dizüstü)

## Kapatma
Karar (`gercek_pozitif` / `yanlis_pozitif` + sebep / `belirsiz`) etiket deposuna yazılır; `bilinen_istisna` ise son kullanma tarihli bastırma önerisi üretilir.
